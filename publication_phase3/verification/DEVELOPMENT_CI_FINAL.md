# Development interval provenance

The frozen release records the WUR-v2 development estimates P1 0.1159994 for the joint candidate and 0.1305460 for the Tier A comparator (ratio 0.8885713). It also records a conditional interval [0.865, 0.911] and a ten-arm simultaneous max-T interval [0.860, 0.918].

The specified Phase 2 audit directory, local audit commit `459a78a8ef0ac7a3e92d15c25be38cc8d86403b6`, deliverables archives, and source calculation for the max-T interval were unavailable in the local workspace and absent from the inspected remote refs. The repository has historical review notes describing the interval and critical value, but the required independent calculation inputs and reproducible script were not recovered. This package therefore preserves the reported interval as a release-record statement and does not include it in newly verified inferential claims. No interval was recreated or guessed.

The independent MSnLib bootstrap interval is separate and was reproduced from the frozen analysis script and committed inputs.
