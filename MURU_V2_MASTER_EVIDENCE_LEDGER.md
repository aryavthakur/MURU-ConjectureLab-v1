## Evidence-type legend

| Code | Meaning |
|---|---|
| EXACT | `EXACT_MATHEMATICAL_RESULT` — an unconditional proof or identity (algebraic, arithmetic, or exact numeric-optimization/proof-search result) |
| PROVEN | `PROVEN_UNDER_STATED_ASSUMPTIONS` — a real derivation/proof, valid conditional on named, disclosed assumptions |
| NUMDER | `NUMERICAL_DERIVATION` — closed-form or deterministic numeric evaluation, not a proof, not a Monte Carlo measurement |
| EMP-S | `EMPIRICAL_SEALED_RESULT` — an executed, hostile-audited, committed Monte Carlo / simulation study |
| EMP-D | `EMPIRICAL_DIAGNOSTIC` — an executed measurement not run through a full hostile-audit/adoption-gate process (includes outcome-blind interim characterizations) |
| PROSP | `PROSPECTIVE_THEORY_PREDICTION` — a stated, unexecuted prediction about an experiment that has not been run |
| GOV | `GOVERNANCE_DEFINITION` — a frozen protocol, threshold, or constant, not itself a scientific finding |
| TENSION | `UNRESOLVED_TENSION` — two or more sealed/frozen sources genuinely disagree or leave a gap that no sealed document adjudicates |
| SUPERS | `SUPERSEDED_INTERPRETATION` — an earlier reading now shown to be incomplete or wrong by a later, higher-quality source, without the earlier source being retracted |
| CONTRA | `CONTRA_INDICATED_REPAIR` — a repair class shown to be structurally incapable of working, not merely untested |
