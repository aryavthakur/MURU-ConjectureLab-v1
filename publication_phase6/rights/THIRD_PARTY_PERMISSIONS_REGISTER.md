# Third-party permissions register

This is a file-level technical assessment, not a legal opinion.

- **MSnLib converted mzML and positive RAW records:** Public Zenodo records are identified as CC BY 4.0. The separate MassIVE MSV000094528 dataset listing identifies CC0 1.0; a single RAW payload was streamed for identity hashing and was not retained. Phase 6 stores repository metadata snapshots and derived validation evidence, not the raw/mzML payload. Any future redistribution must include attribution, DOI/version, transformation notices, and file hashes.
- **WUR:** Phase 5 source review identifies the source dataset as restricted. Raw files and record-level WUR derivatives remain excluded unless the data custodian's terms explicitly permit the contemplated use.
- **MURU model artifacts:** Model JSON/checkpoints may embody training from restricted or separately governed data. No public redistribution is presumed.
- **Comparator model weights:** No third-party weights are included. Code licenses do not grant rights to separately distributed weights.
- **Derived MSnLib outcomes:** A compound-level error table may be a derived record, but its sharing scope has not been definitively cleared. It is excluded from the external Phase 6 bundle.
- **Project-authored assets:** The project owner must confirm ownership and select a license before public release. Sharing with a named scientific reviewer is a separate, recipient-specific decision and remains pending.

No unpublished manuscript, model artifact, or restricted dataset has been sent to any person. No Phase 6 rights register is a public-distribution authorization.
