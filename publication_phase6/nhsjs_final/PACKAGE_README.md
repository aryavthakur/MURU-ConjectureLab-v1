# MURU NHSJS-formatted internal manuscript package

This archive contains the current internal manuscript in anonymous standard-citation, online-citation, and named-master forms, plus Supporting Information. The title-named DOCX/PDF are the anonymous standard-citation review copy.

The standard manuscript is 18 pages, its abstract is 240 words, and the bibliography has 34 references. Supporting Information is 6 pages and contains the detailed methods and machine-readable results tables described in the document.

The package was formatted using the official NHSJS Word templates. It has not been submitted and is not a certification of future journal-policy eligibility. The anonymous file omits direct author metadata, but scientific self-citations and public repository links are retained for provenance and could permit inference of authorship.

The frozen Phase 6 results and limitations were preserved. The package does not contain raw spectra or restricted third-party data. See the validation and anonymization reports for scope and limits.
