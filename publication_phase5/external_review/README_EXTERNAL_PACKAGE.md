# External scientific review package

This package is prepared for a qualified scientist to review the internal manuscript. It contains aggregate results, figures, methods, and bounded technical review materials. It does not contain raw spectra, record-level compound outcomes, restricted WUR-derived records, or model JSON artifacts.

The current rights inventory is provisional and does not constitute legal clearance. In particular, even aggregate derived outputs and project-authored materials require project-owner license confirmation before public posting. This ZIP is not posted or sent; obtain owner confirmation of intended recipient and sharing terms before distribution.

Suggested reading order: research summary; manuscript and supporting information; analytical-chemistry, statistical, and reproducibility packets; feedback form. The primary numerical result can be understood from aggregate manuscript and supplementary tables. Reproduction of the frozen-output statistics requires the separately identified Phase 4 reviewer archive and rights review; it is not included here.

No human external review has occurred. The included request drafts and response form are templates.
