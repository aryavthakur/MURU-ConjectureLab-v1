Genetic programming always returns something, so a raw symbolic-regression score
means nothing on its own. The threshold a candidate must clear is built
empirically, **at its own complexity**, from worlds where no valid structural
conjecture exists.

## The statistic

**The maximum over all 30 seeds of the best validation
R² attainable at complexity ≤ c.**

Taking the max over seeds is what prices in search multiplicity: the protocol
runs the search 30 times and keeps the best, so the null is allowed the same.
A discovered expression is never compared to a naive single-model p-value.

## Design

| Item | Value |
|---|---|
| Calibration worlds | **40** (block `NCAL`) |
| Null constructions | 4, cycled across worlds |
| Seeds per world | 30 |
| Quantile | **95th percentile** |
| Monotonicity | thresholds are made non-decreasing in complexity — a larger hypothesis space cannot make chance fitting harder |
| Disjointness | calibration worlds are the NCAL block and are disjoint from the 100 G4 worlds used to measure the false-positive rate |

### The gap between the median and the threshold is the whole point

At complexity 20 the null **median** best-of-30-seeds R² is
+0.0033 — indistinguishable from zero, which is what a
null should give. The **95th percentile** is
+0.4889. In other words, in a world where no
descriptor-level relationship exists at all, the best of thirty symbolic
searches reaches R² ≈ 0.49 by chance alone.

A candidate compared against a naive single-model null would clear that bar
easily and be reported as a discovery. This is precisely the failure the
master plan's §13.6 calibration exists to prevent, and it is why the threshold
is built from the max-over-seeds statistic rather than a per-run p-value.

### The threshold's own uncertainty

2000-resample bootstrap of the quantile itself; the 95th percentile of a finite set of null worlds is not a precisely known number. The intervals above are wide — at complexity
20 the threshold is +0.4889 with
interval [+0.2603, +0.6859] —
because a 95th percentile estimated from 40 worlds rests on its
top two or three. The point estimate is used as the frozen gate, as
pre-registered; the interval is reported so the table is not read as more
precise than it is, and it is carried forward as a Phase 4 restriction.

## G4 false-positive experiment

Each of the 100 G4 replicates ran the frozen 30-seed
search, the frozen ranking rule and the complete falsification harness.

```
false-positive rate = 0 / 100 = 0.0000
```

| Quantity | Value |
|---|---|
| Numerator (null worlds producing an accepted conjecture) | **0** |
| Denominator (valid null replicates) | **100** |
| Rate | **0.0000** |
| Clopper-Pearson exact 95% interval | **[0.0000, 0.0362]** |

a point estimate of 0/N does not license the claim that the population rate is zero; the interval is the claim. `p = 0` language is not used for a finite simulation count: with
100 replicates the interval, not the point estimate, is
the claim.
