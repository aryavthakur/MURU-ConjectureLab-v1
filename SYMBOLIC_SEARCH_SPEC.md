## Targets

| Target | What it is | Role |
|---|---|---|
| T1 | joint `(Φ, g)` collapse fit, alternating an isotonic shared `Φ` against per-compound scales | fitted for every world; its adequacy test decides H-MAIN |
| **T2** | the estimated scale `ĝ_i`, inverse-variance weighted, as a function of the 12 dimensionless Tier A descriptors | **the governed symbolic target**; every gate, threshold and false-positive count is computed on it |
| T3 | direct `mu = f(E, z)` | **not run** — the plan itself calls it diagnostic and the easiest place to overfit (`DEVIATIONS_P3.md` D2) |

`g` is identified only up to a positive multiplicative constant, so fitted
scales are normalized to unit geometric mean and every comparison is made up to
positive scaling.

### Protected numerics

- **division** — |denominator| < 1e-12 -> invalid
- **inv** — |argument| < 1e-12 -> invalid
- **log** — argument <= 0 -> invalid
- **sqrt** — argument < 0 -> invalid
- **overflow** — |value| >= 1e12 -> invalid
- **nan** — NaN or non-finite -> invalid
- **scoring** — invalid points are excluded from the fit statistic and counted against the candidate; a candidate with more than 0.5% invalid points on the evaluation domain is rejected outright. Invalidity can never improve a score.

Candidate invalidity is never converted into a favourable score.
`tests/test_p3_grammar.py` plants `1/(a-a)` and `log(a-b)` and requires them to
be marked invalid rather than raising or scoring.

## Dimensional discipline

All inputs are dimensionless: energy NCE/30, mass Da/500, counts divided by
their development-corpus median, TPSA/54.5, heteroatom fraction/0.25. A
recovered law is a statement about **dimensionless** quantities and is never
reported as a physical law in raw units.

## Complexity — one metric everywhere

Node count over the parsed tree: variable 1, constant 1, binary operation 1,
unary operation 1; an integer or half-integer power is one unary operation over
its base, so `x**2` costs the same as `square(x)`. Parsing deliberately carries
no positivity assumption, which would restructure `sqrt(a*b)` into
`sqrt(a)*sqrt(b)` and count a tree the engine never searched
(`DEVIATIONS_P3.md` D7).

The same function scores candidate ranking, the Pareto front, null calibration
and the Phase 4 thresholds.

## Candidate equivalence — not string matching

1. symbolic simplification where it is safe and terminates,
2. algebraic equivalence **up to a positive multiplicative constant**,
3. dense noise-free evaluation on an independently generated
   10,000-point Latin hypercube
   (2,000 for within-world clustering), never on
   training points,
4. variable-support comparison,
5. complexity comparison.

Tolerances: relative RMSE after optimal positive rescaling
< 1e-06 ⇒ symbolic-equivalent; `r` >
0.999 and relative RMSE < 0.02 ⇒
functionally equivalent. A high-complexity interpolant with tiny training error
is **not** recovery.

## Seeds and stability

**30 seeds per world**, frozen before any governed run and
recorded in `artifacts/p3_seed_manifest.json`. Per seed the complexity **elbow**
is taken — the smallest complexity within 0.01 of the best
validation R² on that seed's Pareto front. Across seeds, picks are clustered by
numerical fingerprint into expression **families**; stability is that family's
share, and the requirement is ≥ **20/30**.

Stability is never defined by identical expression strings.

Observed selection frequency across all 240 adjudicated worlds:
median **0.60**, first quartile **0.33**.

## Grouped evaluation

Scaffold-group-disjoint train 60% / validation 20% / test 20%, groups filled
largest-first into the currently smallest partition — the Phase 2 rule. Whole
trajectories move together and no scaffold group straddles a boundary;
`tests/test_p3_protocol.py` asserts this and checks that one 80-compound group
cannot dominate a partition.
